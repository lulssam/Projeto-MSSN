# Projeto MSSN 🚀

Final project for the **Modelling and Simulation of Natural Systems** course at ISEL, featuring a Space Invaders-inspired game alongside simulations of natural phenomena.

---

## 📖 About

This project was developed to explore concepts of modelling and simulation of natural and physical systems through interactive visualisations and a classic arcade game. Built entirely in **Java** using the **Processing** framework.

---

## 🗂️ Project Structure

| Module | Description |
|---|---|
| `game/` | Space Invaders — game mechanics, collisions, scoring |
| `particles/` | Particle system simulations |
| `physics/` | Physics-based simulations |
| `fractals/` | Fractal generation |
| `audio/` | Audio integration |
| `ui/` | User interface components |
| `data/` | Data and configuration |

---

## 🎮 Space Invaders

The main module is a Space Invaders clone featuring:

- 👾 **Enemy movement** — wave patterns and increasing difficulty
- 🚀 **Player controls** — movement and shooting mechanics
- 💥 **Collision detection** — bullet and enemy interactions
- 🏆 **Score system** — real-time score tracking
- 🔊 **Sound effects** — audio feedback for game events

## 🚀 Getting Started

### Prerequisites
- [Processing](https://processing.org/download) 4.x or later

### Run

1. Clone the repository
```bash
git clone https://github.com/lulssam/Projeto-MSSN.git
```

2. Open the desired module in Processing (e.g. `game/`)

3. Press the **Run** button in Processing IDE
